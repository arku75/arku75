# Repository map

This page organizes the public repositories in **arku75** without deleting, hiding or archiving them.

> **Authorship note:** a repository being present in this account does **not** automatically mean I am the original author. The account includes original projects, historical repositories, forks, research references, experiments and upstream copies. When a repository is a reference/fork, I treat it as such.
